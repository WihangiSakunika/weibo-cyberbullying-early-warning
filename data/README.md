## Label definitions

- **CHNCI** `y_majority` = majority vote of `label1/label2/label3` (three
  LLM-assisted, human-verified annotation strategies); 1 = cyberbullying
  comment. `incident_label` (1 = CB incident, 0 = non-CB) comes from the
  folder the file sits in.
- **SWSR** `label` = 1 sexist / 0 non-sexist; `category` ∈
  {SA appearance, SCB cultural background, MA microaggression, SO sexual
  offense} (positives only); `target` ∈ {I individual, G generic}.
